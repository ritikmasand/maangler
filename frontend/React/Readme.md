## Getting started with react application.

- We want node js.
- After nodejs is installed, we create a new folder.
- Then we execute a command -> npx create-react-app <app name>
- After executing this command, go inside the folder (cd project name)
- after that type the command - npm start.
- Finally you should be able to see a nice looking react logo.
