## Getting started with react application.

- We want node js.
- After nodejs is installed, we create a new folder.
- Then we execute a command -> npx create-react-app <app name>
- After executing this command, go inside the folder (cd project name)
- after that type the command - npm start.
- Finally you should be able to see a nice looking react logo.

## Component
- The react application can be broken down into various atomic parts. These atomic parts are called components.
- A compnent is a js file.
- This contains the html code with it's reletive js functionality and logic.
- Generally, we put all the components inside a folder called as components,.
- Whatever the file name we give, that should be the function. That is the component name.

- After creating the function, we also need to export it.
- Whichever component we need, we have to import it.
